MDQ 0.1 — Cheatsheet

Syntax, Python API and command line. Every output on this page was produced by mdq 0.1.0 (unit catalogue 0.1.0-draft) when the page was generated by scripts/build_cheatsheet.py. Normative rules are in spec/.

Safe by default: sources are never modified, nothing is fetched, network requests in documents never grant anything, and every error has a stable code and a location.

Documents and metadata

{{document.key}} reads metadata; {{name}} an entry under variables:. Values are escaped text.

---
title: Report
variables:
  team: Engines
  owner: "*Ada*"
---
# {{document.title}}

By {{team}}, owner {{owner}}.
Output
# Report

By Engines, owner \*Ada\*.

Host inputs

inputs= (CLI --input) is the top metadata layer, as variables.*.

Hello, {{reader}}!
Output inputs={"reader": "Grace"}
Hello, Grace!

Calculations

One assignment per line; each block has its own scope; the block is left out of the output (calc_blocks="keep" keeps it). 28 significant digits, half-even.

```calc
price = 120 EUR
quantity = 4
subtotal = price * quantity
tax = subtotal * 21%
total = subtotal + tax
```
Total: {{calc.total}}
Output
Total: 580.8 EUR

Units and temperatures

Conversions round once; unknown units, incompatible dimensions and absolute-temperature arithmetic fail.

```calc
d = 12 miles to km
t = 72 degF to degC
area = 3 m * 4 m
third = 1 / 3
```
Distance {{calc.d}}; {{calc.t}}; {{calc.area}}; {{calc.third}}
Output
Distance 19.312128 km; 22.22222222222222222222222222 degC; 12 m2; 0.3333333333333333333333333333

Money and exchange rates

Currency conversion never fetches a rate: without observations= and a valuation= time (CLI --observations FILE --valuation TIME) it fails with MDQ_SOURCE_UNRESOLVED.

---
variables:
  total: 100 EUR
---
```calc
usd = total to USD
```
In dollars: {{calc.usd}}
Output observations=[EUR>USD 1.0825], valuation=...
In dollars: 108.25 USD

Conditionals and loops

Excluded branches are never evaluated: an import inside one is not even read.

---
variables:
  mode: full
  items: [a, b]
---
:::if {var="mode" equals="full"}
Full report.
:::

:::for {each="items" as="it"}
- item {{it}}
:::
Output
Full report.

- item a
- item b

Variable files

A string starting ./ or ../ and ending .yaml/.yml/.json loads that file as a namespace.

main.md
---
variables:
  team: ./data/team.yaml
---
Lead: {{team.lead}}
data/team.yaml

Declared variables and snapshots

type: declares a typed variable: host-supplied (inputs=) or, with a source:, from a recorded snapshot (snapshot=, CLI --snapshot; made by mdq.test_source). Compile never fetches; a missing value fails, even if unused.

---
variables:
  qty:
    type: number
  price:
    type: number
    unit: USD
    source:
      kind: http
      url: https://example.invalid/p
      format: json
      select: /price
---
{{qty}} items at {{price}}
Output inputs={"qty": 3}, snapshot=[entry]
3 items at 19.99 USD

Packages (.mdq)

A ZIP with a root manifest.yaml; features must include package. Requests never grant: the network stays off unless the host allows it. .mdq.age = whole-package age encryption (PackageFS(data, identities=[...]), then compile(pkg, allow_plaintext=True)).

manifest.yaml
format: mdq
version: '0.1'
entrypoint: document.md
features: [core, calc, package]
title: Guide
requirements:
  network: optional
  hosts: [api.example.org]
document.md
# {{document.title}}
Output of mdq.compile(mdq.PackageFS(data))
# Guide
pkg.requests
{'requirements': {'network': 'optional', 'hosts': ['api.example.org']}, 'security': {'network': 'request'}}

Command line

mdq build|check|sources ENTRY --root DIR (or --package FILE); options --input NAME=VALUE, --snapshot FILE, --observations FILE --valuation TIME, --profile gfm, --calc-blocks keep, --allow-plaintext, -o FILE (never a source file), --format json (one object, schema mdq/cli.schema.json). Offline: no command fetches.

$ mdq build r.md --root .
Total 5 EUR
[exit 0]
$ mdq build r.md --root . --input qty=4
Total 10 EUR
[exit 0]
$ mdq build missing.md --root .
missing.md: MDQ_MISSING_IMPORT: the entry file does not exist
[exit 1]
ExitMeaning
0success
1invalid input (syntax, metadata, references, variables, calc, sources)
2usage error (bad command line, unreadable option file, -o on a source)
3unsupported feature
4denied capability (security)
5resource limit

Python API

Results are frozen dataclasses with exact Decimal values; floats are refused.

from decimal import Decimal
import mdq

files = {"d.md": "```calc\nx = price * 3\n```\nx = {{calc.x}}\n"}
r = mdq.compile("d.md", files, inputs={"price": Decimal("2.50")})
print(repr(r.markdown))
v = r.calc[0].results[0]
print(v.name, v.value, type(v.value).__name__, v.display)
ev = mdq.evaluate("d.md", files, inputs={"price": 4})       # data only
print(ev.calc[0].results[0].value)
try:
    mdq.compile("d.md", {"d.md": "{{nope}}\n"})
except mdq.UndefinedVariableError as e:
    print(e.code, e.path, e.line, e.column)
# also: mdq.DirectoryFS(root), mdq.PackageFS(data), mdq.validate_sources(entry, fs),
#       mdq.test_source(entry, fs, name=..., transport=..., retrieved_at=..., host_policy=..., library_policy=...)
