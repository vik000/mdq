Calculation grammar at a glance

name = expression
operators: +  -  *  /
unary: +x, -x
percentage: 21%
grouping: (2 + 3) * 4
quantity: 12 miles, 72 degF
conversion: value to km
No: functions, strings, loops, ^, inline comments, live fetch

Key calculation rules

TopicRule
VariablesLocal assignments and host/metadata inputs; no forward references; names case-sensitive
PrecedencePercentage → unary → multiplication/division → addition/subtraction → conversion
UnitsDimension checked; incompatible units fail; absolute temperatures are restricted
CurrencyRequires an explicitly supplied dated exchange-rate observation; no automatic fetch
External sourcesDeclared in YAML; reader controls permission; optional library resolver is disabled by default
UnsupportedFunction calls, general programming, implicit multiplication, exponentiation, inline comments
MDQ 0.1 draft — refer to spec/extended-markdown.md, spec/sources-and-permissions.md and spec/calculation-units.md for normative detail.
