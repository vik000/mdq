## Public contract (the behaviour to implement and test)

Transport = callable taking a dict, returning a dict (Python side; Rust side: trait).
- `{"op":"resolve","host":str}` → `{"addresses":[str,...]}`
- `{"op":"get","url":str,"address":str,"headers":dict,"timeout_ms":int,"max_bytes":int}` → `{"status":int,"headers":dict,"body":bytes,"peer":str,"elapsed_ms":int (optional, default 0)}`

`source_fetch(text, name, policy, transport, retrieved_at, allow_network=True, headers=None)`:
- Argument errors: `TypeError` for wrong types (text/name str, policy dict, transport callable, retrieved_at str, allow_network bool, headers dict of str→str); `ValueError` for bad `retrieved_at` (must be `YYYY-MM-DDTHH:MM:SSZ`, real date, hour<24, min<60, sec<60) or invalid headers (empty/non-ASCII/space-colon-CR-LF in name, control chars or non-ASCII in value).
- Flow: `source_validate(text)` → unknown name → UNRESOLVED; variable with no source → UNRESOLVED; `reader:` kind or `csv` format → UNSUPPORTED_FEATURE; `allow_network=False` → SECURITY_DENIED **before any transport call**.
- Loop (n = redirects so far): `policy_decide(policy, url, n)` (denials incl. redirect limit, blocked host, allowlist) → resolve (skipped for IP-literal hosts; every returned address must pass `policy_ip_allowed`, else SECURITY_DENIED; empty/invalid list or malformed → FETCH_FAILED "DNS resolution failed") → get with the address **pinned** to the first validated address; `headers` are sent only to the first origin and dropped for any other origin; `timeout_ms` = remaining budget.
- Response checks: malformed response → FETCH_FAILED; `peer` must equal the validated address (DNS rebinding) else SECURITY_DENIED; cumulative `elapsed_ms` > timeout → FETCH_FAILED (slow-loris); `Content-Length` (non-digits → FETCH_FAILED) or body larger than `max_bytes` → FETCH_FAILED "the response is too large".
- Redirects 301/302/303/307/308: need `Location` (else FETCH_FAILED); resolve with `url_join`; loop detection → FETCH_FAILED "redirect loop"; increment n (policy enforces `max_redirects`, default 0).
- Non-2xx → FETCH_FAILED "HTTP status N". Body must be strict UTF-8 else SOURCE_INVALID. json → `json_pointer_select` + `value_type_check`; text → `value_type_check(..., from_text=True)`.
- Transport exceptions: TimeoutError → FETCH_FAILED "the request timed out"; any other → FETCH_FAILED "the transport failed (ClassName)" (raised `from None`).
- **Messages must never contain URLs, hosts, header values, response body or exception text** (canary tests required).
- Result: `{"name","type","value","unit","retrieved_at","source":{"kind":"http","named":<bool/name>,"origin":<first origin>,"key":<sha256 hex>}}`.
- Source identity = origin + sha256 key, not the URL. A failed fetch never substitutes snapshot/stale data.

`snapshot_apply(text, snapshot)`: snapshot = list of entries `{name,type,value,unit,retrieved_at,source:{kind,named,origin,key}}`. Unknown keys / undeclared names / duplicate names / bad `retrieved_at` / malformed source → SOURCE_INVALID. Declared variable with no entry, or key/type/unit mismatch → SOURCE_UNRESOLVED. Values are type-checked. Returns `{name: {value,type,unit,retrieved_at,source}}`. Never touches a transport.

`url_join(base, ref)`: RFC 3986 §5.2 for an absolute http(s) base; fragment dropped; oracle = `urllib.parse.urljoin` (minus fragment).

Decision key: `sha256` of `json.dumps({"source": {arguments,format,kind,method,reader,select,url}, "type": ty, "unit": unit}, sort_keys=True, separators=(",",":"), ensure_ascii=True).encode()`. The Rust canonical JSON must match byte for byte (lowercase `\uXXXX` escapes, surrogate pairs for non-BMP).

## Reference implementation (Python; validated only for `url_join` — port this)

```python
import hashlib, json, re

def _remove_dots(path):
    out = []
    for seg in path.split("/"):
        if seg == ".": continue
        if seg == "..":
            if len(out) > 1: out.pop()
            continue
        out.append(seg)
    last = path.split("/")[-1]
    if last in (".", "..") and out and out[-1] != "": out.append("")
    return "/".join(out)

def url_join(base, ref):
    ref = ref.split("#", 1)[0]
    b = base.split("#", 1)[0]
    scheme, _, rest = b.partition("://")
    cut = min([i for i in (rest.find("/"), rest.find("?")) if i != -1], default=len(rest))
    auth, tail = rest[:cut], rest[cut:]
    bpath, _, bq = tail.partition("?"); has_q = "?" in tail
    colon = ref.find(":")
    if colon > 0 and ref[0].isalpha() and all(ch.isalnum() or ch in "+-." for ch in ref[:colon]): return ref
    if ref.startswith("//"): return scheme + ":" + ref
    if ref == "": return b
    rpath, _, rq = ref.partition("?"); ref_has_q = "?" in ref
    if rpath == "":
        return f"{scheme}://{auth}{bpath}" + ("?" + rq if ref_has_q else ("?" + bq if has_q else ""))
    if rpath.startswith("/"): path = _remove_dots(rpath)
    else:
        merged = (bpath[:bpath.rfind("/") + 1] if bpath else "/") + rpath
        path = _remove_dots(merged)
    return f"{scheme}://{auth}{path}" + ("?" + rq if ref_has_q else "")

_REDIRECTS = (301, 302, 303, 307, 308)

def source_fetch(text, name, policy, transport, retrieved_at, allow_network=True, headers=None):
    # (argument validation: see contract above)
    d = next((x for x in source_validate(text) if x["name"] == name), None)
    if d is None: raise err("MDQ_SOURCE_UNRESOLVED", "no declared variable has that name")
    spec = d["source"]
    if spec is None: raise err("MDQ_SOURCE_UNRESOLVED", "the variable declares no source")
    if spec["kind"] != "http": raise err("MDQ_UNSUPPORTED_FEATURE", "reader sources need a reader adapter")
    if spec["format"] == "csv": raise err("MDQ_UNSUPPORTED_FEATURE", "CSV sources need a reader adapter")
    if not allow_network: raise err("MDQ_SECURITY_DENIED", "network access was not authorised for this call")
    url = d["url"]; visited = [url]; origin0 = None; total = 0; n = 0
    while True:
        dec = policy_decide(policy, url, n)
        if origin0 is None: origin0 = dec["origin"]
        lim = dec["limits"]
        budget = lim["timeout"] * 1000 - total
        if budget <= 0: raise err("MDQ_SOURCE_FETCH_FAILED", "the request timed out")
        addrs = resolve(transport, policy, dec)          # IP literal: [host]; else op "resolve" + policy_ip_allowed on every address
        send = hdrs if dec["origin"] == origin0 else {}
        resp = tcall(transport, {"op": "get", "url": url, "address": addrs[0], "headers": dict(send),
                                 "timeout_ms": budget, "max_bytes": lim["max_bytes"]})
        status, rh, body, peer, el = check_resp(resp)    # lower-case header names; malformed -> FETCH_FAILED
        if parse_ip(peer) != parse_ip(addrs[0]): raise err("MDQ_SECURITY_DENIED", "the connection did not use the validated address")
        total += el
        if total > lim["timeout"] * 1000: raise err("MDQ_SOURCE_FETCH_FAILED", "the request timed out")
        cl = rh.get("content-length")
        if cl is not None:
            if not (cl.isascii() and cl.isdigit()): raise err("MDQ_SOURCE_FETCH_FAILED", "malformed transport response")
            if int(cl) > lim["max_bytes"]: raise err("MDQ_SOURCE_FETCH_FAILED", "the response is too large")
        if len(body) > lim["max_bytes"]: raise err("MDQ_SOURCE_FETCH_FAILED", "the response is too large")
        if status in _REDIRECTS:
            loc = rh.get("location")
            if not loc: raise err("MDQ_SOURCE_FETCH_FAILED", "redirect without a location")
            nxt = url_join(url, loc)
            if nxt in visited: raise err("MDQ_SOURCE_FETCH_FAILED", "redirect loop")
            visited.append(nxt); url = nxt; n += 1
            continue
        if not 200 <= status <= 299: raise err("MDQ_SOURCE_FETCH_FAILED", f"HTTP status {status}")
        break
    try: doc = body.decode("utf-8")
    except UnicodeDecodeError: raise err("MDQ_SOURCE_INVALID", "the response is not valid UTF-8") from None
    value = json_pointer_select(doc, spec["select"] or "") if spec["format"] == "json" else doc
    c = value_type_check(value, d["type"], d["unit"], spec["format"] == "text")
    return {"name": name, "type": c["type"], "value": c["value"], "unit": c["unit"], "retrieved_at": retrieved_at,
            "source": {"kind": "http", "named": spec["named"], "origin": origin0, "key": decl_key(spec, d["type"], d["unit"])}}

def decl_key(spec, ty, unit):
    s = {k: spec[k] for k in ("arguments", "format", "kind", "method", "reader", "select", "url")}
    doc = {"source": s, "type": ty, "unit": unit}
    return hashlib.sha256(json.dumps(doc, sort_keys=True, separators=(",", ":"), ensure_ascii=True).encode()).hexdigest()
```

(`d["url"]` above is the variable's expanded URL from `source_validate`/`url_template_expand`; check the actual `Declared` field name in `source.rs` — the reference used `d["url"]`.)
